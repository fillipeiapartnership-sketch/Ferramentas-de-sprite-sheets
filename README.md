# Sprite Sheets Studio | InfinitaMente Digital

## Sobre o projeto

Este repositório reúne 18 ferramentas gratuitas desenvolvidas com o auxílio da inteligência artificial, destinadas à criação, edição, manipulação e animação de sprite sheets.

O objetivo é facilitar o desenvolvimento de jogos 2D, 2.5D, animações e outros projetos criativos, tornando essas tecnologias mais acessíveis a desenvolvedores independentes, artistas e criadores de conteúdo.

## Como baixar

Clique no botão verde **Code** e selecione **Download ZIP**. Após concluir o download, extraia os arquivos para uma pasta do seu computador.

As ferramentas desenvolvidas em HTML podem ser executadas diretamente no navegador. Algumas aplicações poderão exigir a instalação de dependências adicionais.

## Aviso importante

As ferramentas são projetos experimentais desenvolvidos com inteligência artificial. Algumas ainda estão em desenvolvimento e poderão apresentar erros, limitações ou problemas de compatibilidade.

Novas funcionalidades, correções e otimizações poderão ser disponibilizadas futuramente.
