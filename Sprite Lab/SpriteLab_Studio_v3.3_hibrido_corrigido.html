04 · Exportação

Ajuste o projeto conforme o tipo de arte. Objetos preservam seus tamanhos originais; animações podem padronizar a escala.

px

Escala automática usa a largura estimada do rosto, com alinhamento horizontal pela cabeça. Se necessário, calibre cada sprite com dois cliques. O desenho nunca será deformado.

Dimensões e proporção

Por padrão, o tamanho dos personagens é aproximado pela largura do rosto, preservando a altura natural do salto. Para resultados mais precisos, selecione um quadro e use Calibrar largura da cabeça.

px

Exportação em PNG com transparência. Tudo é processado no seu próprio computador.

💡 Dica para jogos

Para objetos, preserve o tamanho original. Para animações sem personagens pulando de posição, mantenha Mesmo tamanho ativado. A escala visual é padronizada pela cabeça; a pose pode mudar de altura sem mudar o tamanho do personagem. Se precisar, calibre cada cabeça manualmente. Use Pelos pés quando todas as poses tocam o chão. Se o automático separar braços ou objetos indevidamente, aumente o espaço horizontal permitido ou corrija os recortes no modo Manual.
